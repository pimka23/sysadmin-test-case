## Задача 1: Проверка доступности IP-адресов

**Файл:** `task1-ip-checker/ip_checker.sh`  
**Пример данных:** `task1-ip-checker/ips.txt`

### Описание

Bash-скрипт для максимально быстрой проверки доступности IP-адресов из текстового файла. Скрипт обрабатывает пустые строки, комментарии и невалидные адреса.

### Использование

```bash
chmod +x ip_checker.sh
./ip_checker.sh          # использует ips.txt в текущей директории
./ip_checker.sh list.txt # использовать другой файл
```
### Особенности реализации

* Параллельный пинг всех IP-адресов для максимальной скорости
* Валидация формата IPv4 (0-255 на каждый октет)
* Игнорирование комментариев (#) и пустых строк
* Таймаут ожидания ответа: 1 секунда
* Обработка сигнала Ctrl+C (завершение фоновых процессов)
* Цветовой вывод результатов (✅ доступен / ❌ недоступен)

### Пример входного файла

```text
8.8.8.8
# это комментарий
192.168.1.1
256.1.1.1   # невалидный, будет пропущен
google.com  # не IP, будет пропущен
```

### Пример вывода

```text
=== Чтение и валидация IP-адресов из файла: ips.txt ===
✓ Валидный IP: 8.8.8.8
✗ НЕВАЛИДНЫЙ (пропускаем): 256.1.1.1
✗ НЕВАЛИДНЫЙ (пропускаем): google.com

=== Результаты ===
✅ 8.8.8.8 - ДОСТУПЕН
❌ 192.168.1.1 - НЕДОСТУПЕН
```

## Задача 2: Мониторинг нагрузки на хост

**Файл:** `task2-system-monitor/monitoring.sh`

### Описание

Bash-скрипт для отображения текущей нагрузки на хост по следующим метрикам:

* CPU (загрузка процессора)
* RAM (использование оперативной памяти)
* IO (дисковая активность)
* Network (сетевой трафик)
* Количество процессов

### Использование

```bash
chmod +x monitoring.sh
./monitoring.sh
```
### Особенности реализации

* Проверка наличия необходимых утилит перед выполнением
* Использование стандартных Linux-утилит: top, free, vmstat, ip, ps
* Детальный вывод по каждому сетевому интерфейсу
* Человеко-читаемый формат вывода

### Пример вывода

```text
Нагрузка на CPU:
  Использование CPU: 15.2%

Нагрузка на RAM:
  Всего: 7.6G
  Использовано: 3.2G
  Свободно: 4.4G

Нагрузка на IO (дисковая активность):
  Чтение с диска (блоки/с): 12
  Запись на диск (блоки/с): 45

Нагрузка на Network (трафик):
  eth0:
    Принято: 1254321 байт, 1234 пакетов
    Передано: 654321 байт, 987 пакетов

Количество процессов:
  Всего процессов: 142
```

## Задача 3: Мониторинг CPU процессов

**Файл:** `task3-cpu-monitor/cpu.ps1`

### Описание

PowerShell-скрипт для мониторинга процессов, которые занимают более 50% CPU в течение 10 минут.

### Использование

```powershell
.\cpu.ps1
```

**Важно:** Скрипт должен запускаться от имени администратора для доступа к счетчикам всех процессов.

### Особенности реализации

* Сбор данных в течение 10 минут с интервалом 10 секунд
* Автоматическое усреднение показателей CPU
* Фильтрация системных процессов (idle, _total)
* Игнорирование временно исчезнувших процессов
* Прогресс-бар для визуального отслеживания

### Пример вывода

```text
Анализ потребления CPU
Длительность сбора данных: 10 минут.
Порог срабатывания: > 50% CPU.

Сбор данных завершен. Анализируем результаты...

Имя процесса    Средний CPU (%)
-------------    ---------------
chrome          67.32
python          89.45

Анализ завершен.
```

## Системные требования

### Для task1 и task2 (Linux)

|Компонент|Требование|
|--|--|
|ОС|Любой дистрибутив Linux (Ubuntu, CentOS, Debian и др.)|
|Bash|Версия 4.0 или выше|
|Утилиты|ping, top, free, vmstat, ip, ps|

#### Установка отсутствующих утилит (пример для Ubuntu/Debian):

```bash
sudo apt update
sudo apt install iputils-ping procps sysstat iproute2
```

### Для task3 (Windows)

|Компонент|Требование|
|--|--|
|ОС|Windows 10 / Windows Server 2016 или выше|
|PowerShell|Версия 5.1 или выше|
|Права|Администратор (для доступа ко всем процессам)|
|Локализация|Русская версия Windows (из-за имени счетчика)|

#### Запуск от имени администратора:

```powershell
# Запустите PowerShell как администратор, затем:
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
.\cpu.ps1
```

## Известные ограничения

### task1-ip-checker

* Проверяет только IPv4-адреса (IPv6 не поддерживается)
* Доменные имена не обрабатываются (только валидные IP)

### task2-system-monitor

* Работает только на Linux (не поддерживает macOS и Windows WSL без адаптации)
* Требует русскую локаль для корректного парсинга free -h
* vmstat 1 2 добавляет задержку 2 секунды к времени выполнения

### task3-cpu-monitor

* ⚠️ Работает только на русской версии Windows (счетчик \Процесс(*)\% загруженности процессора)
* Для английской версии требуется заменить счетчик на \Process(*)\% Processor Time
* Усредняет CPU за всё время наблюдения (не проверяет непрерывность нагрузки)
* Не отслеживает процессы, завершившиеся до окончания сбора данных
